# MultiSearchX

[![GitHub stars](https://img.shields.io/github/stars/chirag127/multisearchx?style=flat-square)](https://github.com/chirag127/multisearchx)
[![License](https://img.shields.io/github/license/chirag127/multisearchx?style=flat-square)](LICENSE)

Search multiple terms across 30+ search engines simultaneously. Enter terms, pick engines, search all at once.

## Live Site

**https://search.oriz.in**

Mirror: https://chirag127.github.io/multisearchx/

## Features

- Enter multiple search terms (one per line) — opens a tab for each
- 30+ search engines: Google, DuckDuckGo, Bing, Perplexity, Brave, Phind, YouChat + more
- Append or prepend custom text to all search terms
- AI-powered search engine quick-select
- Custom search engine URLs (add any site that supports URL queries)
- Configurable delay between tab opens
- Real-time search count preview
- Bulk select all / all AI engines
- No signup, no tracking, fully client-side

## Usage

1. Go to https://search.oriz.in
2. Enter search terms (one per line)
3. Select search engines
4. Click Search — tabs open for each term × engine combination

## Tech Stack

Vanilla HTML, CSS, JavaScript. No framework, no build step, no backend.
